# 中国卡通迷你地图

保留卡通公仔标记的轻量静态地图：全国 → 省份 → 城市 → 地点详情。
当前数据目录包含 105 个城市、11,873 条地点记录（无锡 140 条）；数量来自仓库快照，不代表实时覆盖情况。

## 本地运行

无需打包，使用任意静态 HTTP 服务器，不能直接通过 `file://` 打开：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000/#/c/jiangsu-wuxi
```

`config.js` 默认关闭 IP 自动定位。若启用，请配置适用于公开浏览器端的腾讯位置服务 key，并设置服务端允许的来源/额度限制；静态站点中的 key 对访客可见，不是秘密。`local-config.js` 不再无条件引用；本地覆盖需自行在 `config.js` 后、`app.js` 前加入，不要提交私有配置。

## 数据真实性

- 这是静态地点参考地图，不是实时客流、实时打卡或经过核验的热门榜。
- 现有排序、介绍、门票和营业时间来自历史导入/生成数据，部分为模板或 AI 润色；应以场所官方最新信息为准。
- 自动测试仅检查坐标数值范围、内部引用等结构，不证明地点真实、营业中、坐标准确或导航可达。
- 地图使用高德底图和导航；行政区边界依赖外部数据源。断网时城市入口保留，但底图及边界不保证可用。
- 没有新增、推测或编造旅游路线或地点。本轮保留原数据便于后续逐条核验。

## 结构与维护

- `app.js`：hash 路由、视图生命周期、卡通标记、筛选与详情。
- `cities.js`：省级索引。
- `data/*.js`：城市地点和详情，进入城市时才按需加载。
- `city-catalog.js` / `city-loader.js`：轻量城市目录与可重试加载器。
- `vendor/leaflet`：本地 Leaflet 1.9.4，避免地图基础库依赖 CDN 可用性；许可证随库保留。
- `style.css`：响应式与可访问性样式。

修改/新增城市数据后生成并校验目录：

```sh
node scripts/generate-city-catalog.js
```

不要直接编辑生成的城市目录；也不要未经人工核验就把生成介绍标为事实。

## 自动验证

需要 Node.js 22.22.2+（22 LTS）、24.15.0+（24 LTS）或 26+：

```sh
npm ci
npm run check
npm test
```

浏览器测试使用 Playwright，优先使用 `/usr/bin/chromium`，也可指定 `CHROMIUM_PATH`，或运行 `npx playwright install chromium` 安装测试浏览器。浏览器需要可创建 IPC socket 的执行环境。测试截获行政边界与底图请求，使用确定性数据；它们不验证第三方在线地图服务或真实地理边界。

```sh
npm run test:browser
```

没有构建步骤，也没有独立 TypeScript 或 ESLint 配置；`check` 执行 JavaScript 语法与全部 Node/jsdom 回归（包含 105 城渲染与弹窗、路由/定位竞态、加载重试、筛选、数据一致性）。发布由既有 GitHub Pages workflow 管理，测试本身不会推送、发布或部署。
